## 🧠 Why WinOptimiser?

> Windows is a bloated mess. Telemetry running in the background. Junk files piling up. Startup programs you never asked for. Your RAM getting eaten alive. WinOptimiser fixes all of that — for free, in seconds, with zero installations required.

No sketchy third-party software. No trials. No upsells. Just a PowerShell script that does exactly what it says.

## 🚀 Usage

Right-click `WinOptimiser.ps1` → **Run with PowerShell**, or go full terminal:

```powershell
# Allow script execution for this session
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# Fire it up
.\WinOptimiser.ps1
```

You'll land in the interactive menu:


## ❓ FAQ

<details>
<summary><b>Is this safe to run?</b></summary>
<br>
Yes. WinOptimiser only removes known-safe temporary files and does not touch system files, drivers, or the registry. The full source is available for you to read before running.
</details>

<details>
<summary><b>Do I need to install anything?</b></summary>
<br>
Nope. PowerShell is already on your machine if you're running Windows 10 or 11. No additional installs needed.
</details>

<details>
<summary><b>Will it break my PC?</b></summary>
<br>
Extremely unlikely. But if you're paranoid, create a restore point first — the script even offers to do this for you.
</details>

<details>
<summary><b>Why not just use CCleaner?</b></summary>
<br>
CCleaner is 30MB of bloatware with a paid upsell every time you open it. WinOptimiser is a single PowerShell script. You do the math.
</details>

<details>
<summary><b>Does it work on Windows 7/8?</b></summary>
<br>
Untested and unsupported. Upgrade your OS, it's 2025.
</details>
